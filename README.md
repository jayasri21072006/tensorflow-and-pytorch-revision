# TensorFlow & PyTorch Revision 🧠

A personal collection of notes, notebooks, and practice exercises for revising and reinforcing the fundamentals of **TensorFlow** and **PyTorch** — two of the most widely used deep learning frameworks.

This repo is meant as a quick-reference and hands-on practice space, useful for revisiting core concepts before interviews, projects, or exams.

---

## 📂 Contents

| File | Description |
|------|-------------|
| `pytorch_revision.ipynb` | Jupyter notebook covering core PyTorch concepts — tensors, autograd, building and training simple neural networks. |
| `tensorflow basics.pdf` | Notes summarizing the fundamentals of TensorFlow (tensors, operations, basic model building). |
| `tensorflow practice.ipynb - Colab.pdf` | Exported practice notebook (from Google Colab) with hands-on TensorFlow exercises. |

---

## 🎯 Purpose

- Reinforce core deep learning concepts through hands-on code
- Compare how the same ideas (tensors, gradients, models, training loops) are implemented in **TensorFlow** vs **PyTorch**
- Serve as a quick revision guide before interviews or exams

---

## 🛠️ Topics Covered

- Tensors and basic operations
- Automatic differentiation (autograd / `GradientTape`)
- Building simple neural network layers
- Model training basics
- Framework-specific syntax and workflow differences

---

## 🚀 Getting Started

To run the notebooks locally:

```bash
git clone https://github.com/jayasri21072006/tensorflow-and-pytorch-revision.git
cd tensorflow-and-pytorch-revision
pip install torch tensorflow notebook
jupyter notebook
```

Then open `pytorch_revision.ipynb` in Jupyter, or view the PDFs directly for the TensorFlow notes.
